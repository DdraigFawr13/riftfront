Settled rules for this project. Not a changelog: an entry stays while the rule is in force. Change a rule here in the same change that changes the behaviour. Mark ideas Proposed until the owner approves them; mark retired entries SUPERSEDED with a pointer, never delete them.

## D-001 Commander damage: breach first, unblocked lane kept

- **Status:** Accepted (2026-10-31)
- **Decision:** The first playtest uses Territorial Breach (a unit must reach the enemy backfield, starting at columns 7–8 / 1–2, with no defender ahead in its lane). Unblocked Lane stays available as a configurable rules preset for comparison.
- **Why:** Morgan's choice in concept v0.2 section 15; breach should make board position matter, but it may only make matches longer, so both stay testable.
